# 022: 多言語対応(日本語 / 英語)

**ラベル**: roadmap, i18n
**関連仕様**: spec.md §8.12

## 概要
日本語(既定)/ 英語の UI を切り替え可能にする。

## 要求
- [ ] 全テキストを i18n キーに置き換える
- [ ] 日本語(既定)/ 英語の切替 UI を提供する
- [ ] 切替状態を `todo.locale` キーに保存し、リロード後も維持する
- [ ] 日付表示は現在ロケールに合わせた書式を使う

## 検収基準
- [ ] 切替で全 UI 文案が変更される(ハードコードの文案が残っていない)
- [ ] 日付・時刻の書式がロケールに適している
- [ ] 言語切替後、リロードしても維持される
