# 010: アクセシビリティとキーボード操作

**ラベル**: a11y, v1
**関連仕様**: spec.md §5, §7-8

## 概要
キーボードのみで全操作が完結し、スクリーンリーダーにも配慮する。

## 要求
- [ ] 全インタラクション要素に適切な `aria-*` 属性を付ける
- [ ] ラベルとコントロールを `htmlFor` / `aria-label` で関連付ける
- [ ] キーボードのみで追加・編集・削除・フィルタ切替が完了できる
- [ ] 現在の Chrome / Edge / Firefox の 2 メジャーバージョン前で動作する

## 検収基準
- [ ] マウスを使わずに全 CRUD 操作とフィルタ切替ができる
- [ ] スクリーンリーダー(VoiceOver / NVDA のいずれか)で主要操作を読み上げ確認できる
- [ ] 対象ブラウザで動作確認が通る
