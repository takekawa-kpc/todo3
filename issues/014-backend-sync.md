# 014: バックエンド API 同期

**ラベル**: roadmap, infra
**関連仕様**: spec.md §8.6

## 概要
`localStorage` の制限を解決し、デバイス間・タブ間でデータを同期する。

## 要求
- [ ] バックエンド API(タスク CRUD)を導入する
- [ ] デバイス間・タブ間でデータが同期される
- [ ] `localStorage` はオフライン時のキャッシュとして残す
- [ ] オフライン検知と、復旧後の自動再同期
- [ ] データ設計: spec.md §3.2 のデータ構造を API レスポンスとしてそのまま流用

## 検収基準
- [ ] 2 台のデバイスで変更が相互に反映される
- [ ] オフラインで編集 → オンライン復帰で同期される
- [ ] 同期中の競合(同一タスクを 2 つのデバイスで変更)の扱いが定義されている
