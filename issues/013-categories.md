# 013: カテゴリ / プロジェクト

**ラベル**: roadmap
**関連仕様**: spec.md §8.5

## 概要
タスクをカテゴリに分類し、サイドバーでカテゴリ別に切替表示する。

## 要求
- [ ] カテゴリの作成・改名・削除ができる
- [ ] タスクにカテゴリを 1 つ割り当て・変更できる
- [ ] サイドバーでカテゴリ切替と、各カテゴリのタスク数表示
- [ ] データ設計: タスクに `categoryId: string | null` を追加。カテゴリ一覧は `todo.categories` キーで管理

## 検収基準
- [ ] カテゴリ切替で該当タスクのみ表示される
- [ ] カテゴリ削除時に、そのタスクの扱い(未分類移動等)が明確である
- [ ] カテゴリ情報はリロード後も保持される
