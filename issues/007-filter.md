# 007: フィルタ(すべて / 未完了 / 完了済み)

**ラベル**: feature, v1
**関連仕様**: spec.md §2.6

## 概要
3 種のフィルタでタスクを絞り込める。

## 要求
- [x] 「すべて / 未完了 / 完了済み」のフィルタを提供する
- [x] 現在のフィルタを視覚的にハイライトする
- [x] フィルタ状態を `todo.filter` に保存し、リロード後も維持する
- [x] キーボードのみでも切替可能

## 検収基準
- [x] 各フィルタで正しいタスクのみ表示される
- [x] 切替後、リロードしてもフィルタが維持される
- [x] 現在選択中のフィルタがハイライト表示される
