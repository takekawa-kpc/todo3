# 018: キーボードショートカット・Markdown・画像添付

**ラベル**: roadmap, ux
**関連仕様**: spec.md §8.10

## 概要
入力と操作の拡張(ショートカット、Markdown 簡易書式、画像添付)。

## 要求
- [ ] キーボードショートカット: `n` で新規追加フォーカス、`1/2/3` でフィルタ切替
- [ ] タイトルに Markdown の簡易書式(**太字**、*斜体*)のレンダリング
- [ ] タイトルに画像を 1 枚まで添付できる(Data URL で `localStorage` 保存)
- [ ] ショートカットのヘルプ表示(`?` キー等)

## 検収基準
- [ ] ショートカットが有効なキー入力(タイトル入力中)では発火しない
- [ ] Markdown 書式が正しくレンダリングされ、XSS されない
- [ ] 画像添付後、リロード後も表示される
