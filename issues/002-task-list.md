# 002: タスク一覧表示と空状態

**ラベル**: feature, v1
**関連仕様**: spec.md §2.1, §4.2, §4.4

## 概要
保存済みのタスクを一覧表示し、タスクが 0 件の場合に Empty State を表示する。

## 要求
- [x] 表示項目: タイトル、完了ステータス、作成日時
- [x] 作成日時の新しい順に表示する
- [x] 0 件の場合、中央に「タスクはまだありません」を表示する
- [x] 画面右下に「未完了件数」を表示する(例: `3 of 5 tasks left`)

## 検収基準
- [x] 複数タスクが新しい順に表示される
- [x] 全タスク削除後、Empty State メッセージが表示される
- [x] 未完了件数が正しく表示される
