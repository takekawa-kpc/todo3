# 001: タスクの追加

**ラベル**: feature, v1
**関連仕様**: spec.md §2.2

## 概要
入力欄と「追加」ボタンでタスクを登録できる。

## 要求
- [ ] 入力欄と「追加」ボタンを画面上部に配置する
- [ ] Enter キーまたは「追加」ボタンで登録できる
- [ ] 登録後、入力欄が空になりフォーカスが維持される
- [ ] タイトルが空(前後の空白含む)の場合、登録せずエラー表示する
- [ ] タイトル 100 文字を超過する場合は入力できない

## 検収基準
- [ ] 有効なタイトルで登録でき、一覧に新しい順に表示される
- [ ] 空白のみのタイトルは登録されず、赤枠 + エラーメッセージが表示される
- [ ] 100 文字を超える文字は入力できない
