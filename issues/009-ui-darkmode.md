# 009: UI / デザイン(ダークモード対応)

**ラベル**: ui, v1
**関連仕様**: spec.md §4

## 概要
モダンでミニマルな UI を PC 向けに実装し、ダークモードに対応する。

## 要求
- [ ] 中央にマックス幅 480px のカードを配置し、PC 向けに十分な余白を取る
- [ ] 配置順: タイトルヘッダー → 入力欄 → フィルタバー → タスクリスト → 合計表示
- [ ] `prefers-color-scheme` を追従したダークモード対応
- [ ] ホバー、トグル、追加・削除に 150〜200ms のトランジションアニメーション
- [ ] 文字サイズは 16px 以上を基準とする
- [ ] エラー状態: 入力欄に赤枠 + エラーメッセージ

## 検収基準
- [ ] システムのダーク/ライト切替でテーマが追従する
- [ ] 空状態・エラー状態の見た目が仕様通り表示される
- [ ] インタラクションにカクつかないアニメーションがある
