# 012: タグと検索

**ラベル**: roadmap
**関連仕様**: spec.md §8.4

## 概要
タスクに複数タグを付与でき、タイトル・タグで検索できる。

## 要求
- [ ] タスクに複数タグを付与・削除できる
- [ ] タグカラーを数色から選択できる
- [ ] フィルタバー横に検索ボックスを配置し、タイトル・タグを部分一致で検索
- [ ] データ設計: タスクに `tags: string[]` を追加。タグ定義(色を含む)は `todo.tags` キーで管理

## 検収基準
- [ ] タグ付与・検索が即時反映される
- [ ] タグを削除すると、該当する検索結果からも消える
- [ ] タグ定義(色)はリロード後も保持される
