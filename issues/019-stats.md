# 019: 統計・振り返りビュー

**ラベル**: roadmap
**関連仕様**: spec.md §8.9

## 概要
完了タスクの傾向をチャートで表示し、振り返りビューを提供する。

## 要求
- [ ] 完了タスク数の週間 / 月間トレンドをチャート表示
- [ ] 「今週完了したタスク」などの振り返りビュー
- [ ] データ設計: `completedAt: string | null`(完了日時)をタスクに追加

## 検収基準
- [ ] チャートが正しく期間別の集計を表示する
- [ ] 完了解除すると `completedAt` がクリアされ、統計から除外される
- [ ] 過去データの統計がリロード後も正しい
