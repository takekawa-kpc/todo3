# 004: localStorage による永続化

**ラベル**: feature, v1
**関連仕様**: spec.md §3, §4.4, §5

## 概要
タスクとフィルタ状態を `localStorage` に保存し、リロード後も保持する。

## 要求
- [x] `todo.tasks` にタスク配列を JSON として保存する(§3.2 のデータ構造)
- [x] `todo.filter` に現在のフィルタ(`"all" | "active" | "completed"`)を保存する
- [x] JSON パース失敗時はデフォルト値(空配列)にフォールバックし、アプリがクラッシュしない
- [x] `localStorage` の保存失敗時は、画面上部を 5 秒間警告バナーで通知する

## 検収基準
- [x] 追加・完了切替・フィルタ切替のそれぞれがリロード後も保持される
- [x] `localStorage` に不正 JSON を入れてもアプリが起動し、空状態から使える
- [x] 保存失敗シミュレーションで警告バナーが表示される
