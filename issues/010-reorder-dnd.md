# 012: ドラッグ&ドロップによる並び替え

**ラベル**: roadmap
**関連仕様**: spec.md §8.2

## 概要
タスクをドラッグ&ドロップで手動並び替えできる。

## 要求
- [ ] ドラッグ&ドロップで並び替えができる
- [ ] ドロップ位置を示すインジケーターを表示する
- [ ] 並び替え結果を `localStorage` に即座に保存する
- [ ] データ設計: タスクに `order: number`(順序値)を追加

## 検収基準
- [ ] 並び替え後、リロードしても順序が保持される
- [ ] ドラッグ中のドロップ位置が視覚的に分かる
