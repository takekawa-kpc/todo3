# 009: タスクの優先度と期限日

**ラベル**: roadmap
**関連仕様**: spec.md §8.1

## 概要
各タスクに優先度(高/中/低)と期限日を付与できる。期限超過は赤バッジで示す。

## 要求
- [ ] 優先度を 高/中/低 から選択できる(既定: 中)
- [ ] 期限日を日付ピッカーで設定・変更・解除できる
- [ ] 期限を過ぎたタスクに赤いバッジを表示する
- [ ] データ設計: タスクに `priority: "high" | "medium" | "low"`、`dueDate: string | null`(ISO 8601)を追加

## 検収基準
- [ ] 優先度・期限日を保存し、リロード後も保持される
- [ ] 期限切れタスクに赤バッジが表示される
- [ ] 優先度ごとに視覚的な区別がある
