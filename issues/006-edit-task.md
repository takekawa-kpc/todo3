# 005: タスクの編集(インライン)

**ラベル**: feature, v1
**関連仕様**: spec.md §2.5

## 概要
タスクタイトルをクリックするとインライン編集モードになる。

## 要求
- [ ] タイトルクリックで編集モードに入る
- [ ] Enter またはフォーカスアウトで保存する
- [ ] Escape キーで編集をキャンセルする
- [ ] 空白のみのタイトルは保存しない(元の値を維持)

## 検収基準
- [ ] 編集 → Enter で新しいタイトルが保存される
- [ ] Escape で元のタイトルに戻る
- [ ] 空白で保存するとエラー扱いとなり元の値が維持される
