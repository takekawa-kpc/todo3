# 006: フィルタ(すべて / 未完了 / 完了済み)

**ラベル**: feature, v1
**関連仕様**: spec.md §2.6

## 概要
3 種のフィルタでタスクを絞り込める。

## 要求
- [ ] 「すべて / 未完了 / 完了済み」のフィルタを提供する
- [ ] 現在のフィルタを視覚的にハイライトする
- [ ] フィルタ状態を `todo.filter` に保存し、リロード後も維持する
- [ ] キーボードのみでも切替可能

## 検収基準
- [ ] 各フィルタで正しいタスクのみ表示される
- [ ] 切替後、リロードしてもフィルタが維持される
- [ ] 現在選択中のフィルタがハイライト表示される
