# 021: データのエクスポート / インポート

**ラベル**: roadmap
**関連仕様**: spec.md §8.11

## 概要
タスクデータを JSON で書き出し/読み出しできる。

## 要求
- [ ] JSON 形式でのエクスポート(ファイルダウンロード)
- [ ] インポート(ファイル選択)
- [ ] インポート時のマージ方法選択: 上書き / ID 一致で更新
- [ ] 不正な JSON・未知のスキーマのファイルは拒否し、エラー表示する

## 検収基準
- [ ] エクスポートした JSON を別の環境でインポートして復元できる
- [ ] マージ方法ごとに期待通りの結果になる
- [ ] 不正ファイルではデータが壊れない
