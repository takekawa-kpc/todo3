# 018: 通知とリマインダー

**ラベル**: roadmap
**関連仕様**: spec.md §8.8

## 概要
Web Notifications API で期限前にブラウザ通知を送る。

## 要求
- [ ] ブラウザの通知許可を確認する導線を 1 回だけ表示する
- [ ] 期限 1 時間前・当日にブラウザ通知を送る
- [ ] リマインダー時刻を各タスクに設定可能
- [ ] 通知クリックで該当タスクへフォーカス(同一タブが開いていれば)

## 検収基準
- [ ] 通知許可後、条件成立時に通知が届く
- [ ] 通知は同一イベントで 1 回のみ(重複通知しない)
- [ ] 通知拒否時もアプリは通常動作する
