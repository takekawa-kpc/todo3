# 017: ユーザー認証と共有

**ラベル**: roadmap, auth
**関連仕様**: spec.md §8.7

## 概要
ログイン機能と、リストの他ユーザーへの共有を提供する。

## 要求
- [ ] メールアドレス + パスワード、または OAuth(GitHub / Google)でログイン
- [ ] ログアウトができる
- [ ] リストを URL 経由で他ユーザーと共有(読み取り専用 / 編集権限あり)
- [ ] データ設計: API レスポンスに `ownerId: string`、`sharedWith: string[]` を追加

## 検収基準
- [ ] 認証済みユーザーのみ自分のリストを操作できる
- [ ] 共有リンクで読み取り専用ユーザーが閲覧できる
- [ ] 共有の付与・解除が即時反映される
