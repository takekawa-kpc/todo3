# 013: サブタスク

**ラベル**: roadmap
**関連仕様**: spec.md §8.3

## 概要
親タスクにサブタスクを追加でき、サブタスクがすべて完了すると親も自動的に完了する。

## 要求
- [ ] 親タスクにサブタスクの追加・削除ができる
- [ ] サブタスクの完了状況(例: `2/3`)を親タスクに表示する
- [ ] サブタスクがすべて完了した時点で、親タスクを自動的に「完了済み」にする
- [ ] データ設計: `subtasks: Task[]` を再帰的に持つ、または `parentId: string | null` でフラット管理

## 検収基準
- [ ] サブタスク全完了で親が自動的に完了する
- [ ] 完了済みの親を再実行するとサブタスクの完了状態もリセットされる(任意)
